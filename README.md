# Sujash — Filmmaker Portfolio

A bespoke, high-end personal filmmaker portfolio website for **Sujash** — Director, Screenplay Writer, and Dialogue Writer with 2 years of experience in Tamil cinema.

---

## 🎬 Highlights

- **Cinematic WebGL Hero**: Integrated `<DarkVeil />` organic fluid shader with real-time atmosphere tone controls (`Gold`, `Noir`, `Velvet`, `Crimson`).
- **Profile & About**: Clean portrait-focused design, verified credits, and bio.
- **Filmography**: Showcasing short films ***Gangsta*** and ***Sarguna*** (Writer · Actor) shot on iPhone.
- **YouTube Channel**: Dedicated spotlight for [BigMakers](https://www.youtube.com/@BigMakers-p6k).
- **Screenplay Reader**: Interactive modal reading Courier Prime formatted scene excerpts.
- **Directorial Vision**: Breakdown of visual framing, pacing tension, and character dynamics.
- **Responsive & Lightweight**: Optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Custom CSS Design System, Vanilla JavaScript
- **Graphics**: WebGL shader via `ogl` library
- **Components**: `<DarkVeil />` WebGL canvas shader (React Bits)
- **Local Server**: Lightweight Node.js static file server

---

## 🚀 Getting Started

### 1. Clone & Run Locally
```bash
# Clone repository
git clone https://github.com/Sujash15/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local server
node server.js
```

### 2. View in Browser
Open `http://127.0.0.1:3000/` or launch `index.html` directly.
